VAGABOND Studio Website

VAGABOND Studio is an independent game development studio dedicated to creating immersive and engaging video game experiences. This repository contains the source code for the official VAGABOND Studio website, serving as the central hub for showcasing our games, sharing news and updates, and connecting with our community.
🖥️ Tech Stack

    Frontend: React.js – Modern and dynamic UI rendering

    Backend: Node.js – Scalable server-side environment

    Authentication: JWT (JSON Web Token) – Secure authentication and session management

    Database: MongoDB – Flexible NoSQL database for content and user data

    Styling: Bootstrap – Responsive and mobile-first UI framework

🚀 Features

    Game Showcase – Display details, screenshots, and trailers of our latest and upcoming titles

    News & Updates – Keep players informed with development logs, announcements, and patch notes

    Contact & Feedback – Allow visitors to reach out directly for support, press inquiries, or collaborations

    Responsive Design – Optimized for desktop, tablet, and mobile devices
